# 연출 만드는 법

차례:
1. trauma 모델과 수치 범위
2. 이징 고르는 표
3. 나머지 연출(번쩍임, 넉백, 숫자 팝, 파티클, 멈춤)
4. 접근성 설정

예시는 pygame-ce 2.5, 60fps 고정 틱, 낮은 해상도 표면을 정수 배율로 키우는 구성을 전제한다.

## 1. trauma 모델 (흔들림이 왜 좋게 느껴지나)

`[0, 1]` 사이의 `trauma` 값 하나를 둔다. 사건이 trauma를 **더하고**, 매 프레임 일정하게
**줄어든다**. 실제 흔들림은 `trauma^2`(또는 `^3`)라서:

- 작고 잦은 사건은 화면을 거의 건드리지 않고(낮은 trauma를 제곱하면 아주 작다),
- 큰 사건은 세게 친다(높은 trauma를 제곱해도 거의 그대로),
- trauma가 0으로 줄어드니 흔들림은 **늘 저절로 끝난다**.

오프셋은 `최대값 * 흔들림 * noise(t)`다. 시간에 따라 노이즈나 사인 합을 뽑는다. 프레임마다 새
`random()`을 쓰면 흔들림이 아니라 지지직이 된다.

```python
def shake_axis(seed, t):
    # 애드온 없이 쓰는 1차원 노이즈 비슷한 것: 서로 나누어떨어지지 않는 속도의 사인을 겹친다
    return 0.6 * math.sin(t * 11.0 + seed) + 0.4 * math.sin(t * 23.0 + seed * 2.0)
```

시작 수치(256x192 해상도 기준): 최대 오프셋 `(4..8, 3..5)`픽셀, 감쇠 `1.0..1.5` trauma/초,
타격 하나의 trauma `0.15`(약) ~ `0.8`(강). 회전은 도트 화면에서는 픽셀이 뭉개지니 쓰지 않는다.

## 2. 이징 고르는 표

| 목적 | 이징 | 식 | 메모 |
|------|------|----|------|
| 튀어나옴(팝) | overshoot | `ease_out_back` | 목표를 지나쳤다가 돌아온다 |
| 통통 튀는 착지 | bounce/elastic | `ease_out_bounce` | 아껴 쓴다. 만화처럼 읽힌다 |
| 멈춰 섬, 감속 | ease-out | `1 - (1 - k) ** 3` | "와서 선다"의 기본 |
| 준비 동작 | ease-in | `k ** 3` | 빠른 동작 앞의 느린 시작 |
| 양 끝이 부드러운 이동 | ease-in-out | `0.5 - 0.5 * cos(pi * k)` | 화면 전환, 메뉴 |

도구가 바뀌어도 **곡선 선택**은 같게 한다.

## 3. 나머지 연출

- **번쩍임:** 맞은 스프라이트를 1~3프레임 흰색으로 그린다(흰 실루엣을 미리 만들어 둔다).
- **넉백:** 맞은 방향 반대로 짧고 제한된 힘을 준다. 조작을 잠깐만 막고 길게 막지 않는다.
- **숫자, 글자 팝:** 점수나 "+100"이 떠오르며 흐려지고 ease-out으로 멈춘다. 가로 흔들림을 조금
  무작위로 줘서 연달아 맞은 숫자가 부채꼴로 퍼지게 한다.
- **파티클:** 맞은 자리에서 짧게 터지는 불꽃, 먼지, 조각. 목록을 미리 만들어 재사용하고, 타격마다
  만들고 버리지 않는다. 1~2픽셀 사각형이 도트 화면에 가장 잘 맞는다.
- **멈춤 프레임:** 본문의 히트스톱. 중요도에 따라 2프레임(약) ~ 9프레임(강). 공격자와 맞은 쪽만
  멈추고 세상은 돌게 할 수도 있다.
- **준비와 여운:** 큰 동작 앞의 작은 웅크림과 뒤의 자리 잡기가 무게로 읽힌다.
- **줌, 화면 색 펀치:** 큰 순간에만, 짧게. 도트 화면에서는 정수 배율 줌(1배 → 2배 영역)만 깔끔하다.

## 4. 접근성 (설정으로 넣는다)

- **흔들림 줄이기**: trauma 출력에 0~100% 설정을 곱한다(기본 60~80%).
- **번쩍임 줄이기/끄기**(광과민성): 흰 번쩍임을 고정 색조로 바꾼다. 켠 상태에서도 큰 면적의 번쩍임은
  1초에 3회 이하
  ([WCAG 2.3.1](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)).
- **화면 움직임 줄이기**: 줌 펀치를 끈다.
